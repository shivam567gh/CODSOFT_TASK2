# CodSoft Data Analytics Internship - Task 2

## Project Overview
This repository contains the code and implementation for Task 2 of the Data Analytics Internship at CodSoft. The focus of this task is Exploratory Data Analysis (EDA) to uncover underlying data distributions, statistical summaries, and variable relationships.

## Dataset Information
* **Dataset Used:** Cleaned Online Food Delivery Dataset
* **Tool Used:** Python, Pandas, Matplotlib, Seaborn

## Key Steps & Implementation
* Generated descriptive statistics (mean, median, standard deviation, and percentiles) for numerical features.
* Performed categorical frequency analysis across variables such as occupation and monthly income.
* Conducted cross-tabulation analysis to evaluate relationships between customer demographics and feedback sentiment.
* Detected data anomalies and outliers using statistical box plots.

## How to Run
1. Clone the repository and navigate to the project directory.
2. Ensure the required libraries (`pandas`, `matplotlib`, `seaborn`) are installed.
3. Open the Jupyter Notebook (`.ipynb`) file and run the analysis cells.
